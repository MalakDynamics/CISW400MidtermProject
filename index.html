STEP 02 Basic Movements

item 02 • Moving Objects with GSAP via gsap.to()

Moving Obects With GSAP: gsap.to()

The most basic way to move an object with GSAP is the gsap.to() function. In gsap, this instruction is called a 'tween.'

These more basic movements are easily accomplished with CSS classes, but let's start with just trying to move an object. gsap.to() will move an object from it's original position to a new position that you define in its variables.

The parameters taken are a target object, written as you would a querySelector target ('.box', '#box', etc.), and an object with all the properties for the animations like positioning and appearence.
